# kylebolton.me

Personal website featuring experimental typography and CSS animations inspired by David Rudnick's design aesthetic. Built with Next.js 15, React, and Tailwind CSS.

## Features

- Single-page layout with seamless scrolling
- Typography-forward design with brutalist digital aesthetic
- Interactive CSS background with mouse-following elements
- Responsive design with mobile-first approach
- Experimental typography with glitch effects

## Tech Stack

- **Framework**: Next.js 15 with App Router
- **UI Library**: React 18+
- **Component Library**: Shadcn/ui
- **Styling**: Tailwind CSS
- **Typography**: Custom typography inspired by David Rudnick
- **Animation**: CSS animations for UI elements
- **State Management**: React Context API and/or Zustand
- **Deployment**: Vercel

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/kylebolton-website.git
   cd kylebolton-website
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Project Structure

- `src/app`: Main application pages
- `src/components`: React components
  - `src/components/ui`: UI components from Shadcn
  - `src/components/sections`: Page section components
  - `src/components/layout`: Layout components
- `src/lib`: Utility functions and hooks
- `public`: Static assets

## Deployment

The site is configured for easy deployment on Vercel:

```bash
npm run build
```
